## 0.1.0 - 2026-08-26

### Added

- Exact Minecraft Java UUID-to-Locator-Bar color calculation for Java 1.21.6 through 26.2.
- Streaming scans of plain CSV and Zstandard-compressed CSV datasets.
- Resumable download and integrity verification for the pinned 65,936,987-profile snapshot.
- Optional concurrent Mojang username refresh for matched UUIDs.
- Atomic CSV output with dataset and verification provenance.
- Cross-platform tests, GitHub CI, tagged release builds, and contributor documentation.
