# Code of conduct

## Our standards

Project participation should be welcoming, constructive, and focused on improving the software. Examples of expected behavior include:

- Using respectful and inclusive language.
- Accepting technical feedback without personal attacks.
- Giving clear, reproducible evidence when reporting problems.
- Respecting user privacy and never posting credentials or private player datasets.
- Focusing criticism on code and behavior rather than people.

Harassment, discrimination, threats, deliberate disclosure of private information, and sustained disruptive behavior are not acceptable.

## Enforcement

Maintainers may edit or remove contributions that violate these standards and may temporarily or permanently restrict participation. Enforcement decisions should consider context, impact, prior behavior, and the safety of affected participants.

Report conduct concerns privately through the repository's available maintainer contact channel. If no private channel is configured, open a minimal public issue requesting private contact without describing sensitive details.

## Scope

This code of conduct applies in the repository, issue tracker, pull requests, release discussions, and other spaces where someone is representing the project.
